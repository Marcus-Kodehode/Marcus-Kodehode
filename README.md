## `$ cat om-meg.md`

Jeg er **Marcus**, full-stack-utvikler fra Sande i Vestfold. Jeg driver **[Børresen Digital](https://www.borresendigital.no)**, et enkeltpersonforetak som lager nettsider, bookingsystemer og webapplikasjoner for små bedrifter og foreninger, og som drifter dem etterpå.

Jeg liker best å eie hele veien: datamodellen, API-et, grensesnittet, testene, deployen og overvåkingen etterpå. Min egen nettside er også et alt-i-ett-system for foretaket, med CMS, CRM, tilbud, regnskap etter bokføringsloven og egen driftsovervåking, bygget på Cloudflare Workers.
